Think of an Autonomous Agent Chain like an Olympic relay team. Instead of asking one slow AI bot to do everything, eight specialized AI agents work together—each doing one specific job with verified precision, then passing the baton in milliseconds.

Inbound Telemetry Payload (LIV) LIVE INBOUND SIGNAL

Inbound Telemetry Payload (LIV) is the typed state envelope every agent in the PipeFish graph consumes at its entry edge. It carries origin context, intent classification, routing directives, prior subagent artifacts, and security attestation - everything a node needs to execute without side-channel communication. Agents never query upstream. They read the envelope.

INBOUND VOICE / TEXT - B2B SaaS Technical Support: "Hello, we are experiencing an API authentication outage on our production tenant. I need to escalate this to a Tier 2 engineer immediately and check system status."

Schema Field Reference
Field Type Description

classification.intent string Intent label used for routing decisions
classification.priority P0–P3 P0 = critical / immediate, P3 = background
classification.flags array Anomaly tags applied at ingestion
routing.graph_topology enum Execution pattern for this chain instance
routing.ttl_ms integer Max chain execution window in milliseconds
state.artifacts array Structured outputs emitted by prior nodes
security.hmac_signature hex Payload integrity attestation
security.pqc_ready boolean Indicates ML-KEM hardening applied
observability.cost_tracking object Per-chain token and cost telemetry
