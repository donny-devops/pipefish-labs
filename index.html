Inbound Telemetry Payload (LIV) LIVE INBOUND SIGNAL

Inbound Telemetry Payload (LIV) is the typed state envelope every agent in the PipeFish graph consumes at its entry edge. It carries origin context, intent classification, routing directives, prior subagent artifacts, and security attestation - everything a node needs to execute without side-channel communication. Agents never query upstream. They read the envelope.

INBOUND VOICE / TEXT - B2B SaaS Technical Support: "Hello, we are experiencing an API authentication outage on our production tenant. I need to escalate this to a Tier 2 engineer immediately and check system status."
